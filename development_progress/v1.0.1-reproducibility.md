## Executable foundation utilities

`src/ortheon/reproducibility.py` provides:

- canonical experiment-ID generation,
- Python/NumPy/PyTorch seed setup when those frameworks are available,
- lightweight runtime/package metadata capture,
- JSONL experiment event logging.

The helper deliberately does **not** claim universal bit-for-bit GPU determinism. Accelerator/framework-specific determinism policies must be added alongside the actual model pipelines in later versions.

## Release gate assessment

A fresh clone can now determine:

- where datasets and generated data belong,
- where model weights belong,
- which metadata must identify experiments/checkpoints,
- how experiment IDs and logs are formatted,
- how provenance is expected to be preserved,
- what Ortheon currently is and is not attempting to implement.
