# Dataset Schemas

Machine-readable Ortheon-Parse schemas will be introduced during v1.1.x.

Planned schema families:

- `primitive` - P1 visual/vector primitives,
- `token` - P2 recognized text/symbol tokens,
- `entity` - P3 engineering entities,
- `relation` - P4 typed relationships,
- `constraint` - P5 engineering constraints,
- later standards interpretation and reasoning records.

The schemas must preserve provenance, confidence, and alternative hypotheses rather than recording only the selected prediction.
