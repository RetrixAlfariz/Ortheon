# v1.0.0 Foundation Checklist

This file records the concrete completion criteria for Ortheon v1.0.0, the repository and research-foundation milestone.

## Scope

v1.0.0 does **not** train or ship an engineering vision model. It establishes the contracts that later versions will depend on.

## Required outputs

- [x] Research branch exists.
- [x] Dataset strategy is documented.
- [x] Development roadmap exists.
- [x] Live development status exists.
- [x] Repository README explains Ortheon, current scope, architecture, and version status.
- [x] Contribution/research workflow is documented.
- [x] Dataset storage policy and repository hygiene are defined.
- [x] Initial configuration/package skeleton exists for later implementation.
- [x] Initial EIR design notes exist without prematurely freezing the schema.
- [x] Initial evaluation philosophy is documented.

## Release gate

v1.0.0 is complete when a new contributor can answer, from repository documentation alone:

1. What problem does Ortheon solve?
2. What is explicitly in and out of v1 scope?
3. What datasets will be used and why?
4. What is the P0-P7 parsing hierarchy?
5. What is EIR/EDL intended to represent?
6. What is the current development priority?
7. Where should large datasets and generated artifacts live?
8. What must be proven before model training begins?
